# Package `projectkoios.physkit.qm.piab2d`

## Current responsibility

This package owns two-dimensional homogeneous-Dirichlet particle-in-a-box
models. `Piab2D` is the rectangular analytical model. `ObliquePiab2D` defines a
bounded direct-basis parallelogram for inverse-metric finite differences. These
contracts do not represent periodic reciprocal-space free particles.
