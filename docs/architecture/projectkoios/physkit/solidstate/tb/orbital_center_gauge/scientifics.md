# Orbital-center gauge scientific contract

The transformation changes the matrix representation associated with explicit
orbital-center phases. It does not change the represented spectrum at a fixed
reciprocal coordinate. Reciprocal shifts generally induce basis sewing rather than
ordinary periodic equality in the full-center representation.

The module does not infer center positions or establish compatibility between two
independently supplied bases.
