# Slater–Koster parameter-group scientific contract

Parameter sharing is an explicit modeling statement:

$$
g(b_1)=g(b_2)
\quad\Longrightarrow\quad
V(b_1)=V(b_2)
$$

within the represented model. The converse physical claim is not made: equal numerical
parameters do not prove that two bonds are symmetry equivalent or chemically identical.

The identifier has no intrinsic semantics such as

$$
\operatorname{id}_g\not\equiv
\text{``first neighbor''},\quad
\text{``silicon''},\quad
\text{or ``accepted fit''}.
$$

Those interpretations belong to a concrete client composition and its retained
scientific evidence.

The module stores no prior distributions, covariance matrices, fit objectives,
regularization strengths, uncertainty intervals, provenance records, or acceptance
thresholds. Passing software validation establishes only record integrity.
