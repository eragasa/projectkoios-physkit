# `RealCubicOrbitalComponentEnum` scientific contract

An admitted component name identifies a coordinate label; it does not assert that a hopping table or physical model exists for that component.

The represented relation

$$
\lambda\in\{s,p_x,p_y,p_z,d_{xy},d_{yz},d_{zx},d_{x^2-y^2},d_{3z^2-r^2}\}.
$$

is a mathematical or structural software contract. Passing construction and tests
establishes conformance to that contract only; it does not establish material accuracy,
parameter acceptance, convergence, independent verification, or experimental agreement.

It does not include spin, total-angular-momentum labels, complex spherical harmonics, or f orbitals.
