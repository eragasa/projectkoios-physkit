# `SparseBlockHoppingBlochEvaluation` scientific contract

The record correlates a sparse real-space hopping model with its sampled sparse
reciprocal matrix field while preserving basis, gauge, energy reference, units, and
coordinate ordering.

Sparse result storage is a represented numerical property. It does not establish
physical locality, Hermiticity, band accuracy, or model validation.
