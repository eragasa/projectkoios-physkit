# `FermiDiracThermalDensityOfStatesRequest`

## Responsibility

The request correlates one normalized Gaussian or histogram DOS result with a
positive-temperature `FermiDiracState` in the same energy unit. It exposes the
correct DOS energy coordinates and derives reciprocal-energy and thermally
active density units.
