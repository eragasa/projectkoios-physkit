# `FermiDiracThermalDensityOfStates`

## Responsibility

This result correlates the complete thermal-DOS request with unitless
occupations, occupied and unoccupied DOS, the reciprocal-energy thermal window,
thermally active DOS, and numerical occupied/unoccupied state-density
integrals.

The result records a representation-dependent transform. It does not claim that
a finite broadened grid or histogram exactly reproduces the sampled-state
particle-density target.
