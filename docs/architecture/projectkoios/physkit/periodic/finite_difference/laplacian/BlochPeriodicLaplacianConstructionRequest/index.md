# Class `BlochPeriodicLaplacianConstructionRequest`

The frozen, slotted `DataObject` binds one `PeriodicFiniteDifferenceGrid` to one
dimension-matched `BoundaryTwistLift`. Twist components are dimensionless turns
in the direct primitive-axis basis. The action reduces the lift and represents
the result in quotient-seam gauge.
