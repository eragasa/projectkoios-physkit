# `DenseBlockHoppingTerm` scientific contract

The record represents one dense retained-basis coefficient $T(\mathbf R)$ at an
ordinary-lattice displacement. Rows and columns refer to the same ordered basis
owned by the eventual dense model.

Dense storage does not imply nonlocality, physical completeness, Hermiticity, or
material validation.
