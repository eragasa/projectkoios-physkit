# Class `EmbeddedDirectLattice2DSerializationError`

This `ValueError` subtype reports a strict embedded-lattice JSON wire-contract
violation. It gives callers one domain-specific failure type for malformed or
oversized text, schema mismatches, duplicate or invalid fields, non-finite or
mis-typed values, invalid units, and invalid reconstructed geometry.
