# Module `projectkoios.physkit.linalg.matrix_norms.spectral`

The module owns:

- [`SpectralMatrixNorm`](SpectralMatrixNorm/index.md), the quantity-aware spectral norm;
- [`SparseSpectralNormOptionsEnum`](SparseSpectralNormOptionsEnum/index.md), the explicit
  sparse representation-path selector.

The module contains no local singular-value algorithm. Complete dense and iterative CSR
numerics remain Optimization-owned.
