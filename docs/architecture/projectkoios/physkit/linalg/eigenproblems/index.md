# Package `projectkoios.physkit.linalg.eigenproblems`

## Current responsibility

This package owns unit-aware scientific eigendecompositions of represented
finite operators. It composes but does not duplicate the unit-free algorithms
under `projectkoios.physkit.numerics.eigenproblems`.

Only exact real-symmetric dense and sparse operators are currently supported.
No complex-Hermitian decomposition contract is implied.
