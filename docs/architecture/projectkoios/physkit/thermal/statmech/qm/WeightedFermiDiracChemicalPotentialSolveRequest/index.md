# `WeightedFermiDiracChemicalPotentialSolveRequest`

## Responsibility

The request correlates the existing chemical-potential solver, explicit energy
levels, one positive state weight per level, positive thermal energy, and a
target strictly inside the total available state weight. State weights and the
target use one exact physical or unitless unit.
