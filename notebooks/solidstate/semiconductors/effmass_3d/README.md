# Three-dimensional effective-mass laboratories

- [`primitive-cell.ipynb`](primitive-cell.ipynb) applies the reviewed 2D
  conventions to a three-dimensional nonorthogonal primitive cell, Cartesian
  effective-mass tensor, reciprocal-mode spectrum, normalized full-zone 3D DOS,
  and volume-normalized Bloch plane waves.

The maintained laboratory uses synthetic illustrative geometry and mass values.
It is numerical evidence for the idealized model, not a DFT calculation,
material parameterization, or scientific validation for silicon.
