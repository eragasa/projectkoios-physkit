# Two-dimensional checkerboard-potential Bloch laboratories

[`intrinsic-semiconductor-statistics.ipynb`](intrinsic-semiconductor-statistics.ipynb)
uses the maintained PhysKit reciprocal-space checkerboard Hamiltonian to
calculate full-zone bands, the first complete gap, a package-normalized 2D
density of states, exact intrinsic sheet carriers, and a separate nondegenerate
2D comparison.

The laboratory is an idealized model and does not claim a material-specific
band structure or pedagogical validation.
